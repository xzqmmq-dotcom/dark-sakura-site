# Dark Sakura — проект сайта

## Запуск
1. Распакуйте архив.
2. Откройте папку `dark-sakura-site` в VS Code.
3. Установите расширение **Live Server**, если его ещё нет.
4. Нажмите правой кнопкой на `index.html` → **Open with Live Server**.

Можно также открыть `index.html` в современном браузере, но для корректной работы JavaScript-модулей рекомендуется локальный сервер.

## Что работает
- Каталог из 8 демонстрационных товаров.
- Поиск по названию, описанию, категории и тегам.
- Фильтры по категориям и сортировка.
- Корзина: добавление, удаление, количество, итоговая сумма.
- Сохранение корзины в `localStorage`.
- Модальное окно входа и регистрации с валидацией.
- Canvas-анимация лепестков с реакцией на курсор.
- Плавное появление секций и мобильное меню.
- Форма контактов формирует письмо через почтовое приложение.
- Встроенная Яндекс.Карта Караганды.

## Что нужно подключить перед реальным запуском
Авторизация, социальный вход, отправка формы, оформление заказа и оплата сейчас демонстрационные. Для настоящего магазина понадобятся сервер, база данных, безопасная авторизация, API заказов и платёжный провайдер. Замените демонстрационные ссылки соцсетей и тестовые отзывы на реальные данные.

## Структура
- `index.html` — разметка.
- `styles/variables.css` — дизайн-токены.
- `styles/main.css` — базовые стили и сетки.
- `styles/components.css` — карточки, корзина, модалка, карта.
- `styles/animations.css` — анимации.
- `js/store-data.js` — каталог.
- `js/cart.js` — состояние и логика корзины.
- `js/ui-modal.js` — окно авторизации.
- `js/sakura-canvas.js` — Canvas-анимация.
- `js/main.js` — инициализация и связь компонентов.
